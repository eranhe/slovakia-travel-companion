# Product Spec (MVP scope)

## Family trip context

Herskovitz family — Eran, Revital, Omer (11), Rotem (8). Slovakia & Poland, August 2026.

## MVP capabilities (phased)

1. **Foundation (Phase 1)** — Responsive shell, hash routes, RTL/Hebrew
2. **Access** — Simple hardcoded client-side password check
3. **Trip data** — Bundled dedicated trip, documents, 10-day structure
5. **Places (Phase 5)** — Waze links, weather adapters
6. **Itinerary (Phase 6)** — Timeline, contingencies
7. **Weather review (Phase 7)** — Tomorrow check at 20:30 / on-open
8. **Content (Phase 8)** — Command center, packing, phrasebook
9. **Maps (Phase 9)** — Planned/visited maps, check-ins
10. **Photos & journal (Phase 10)** — Local media and journal

## Non-goals (current task)

- No generic trip creation, source-file upload, fact review, or conflict-resolution UI
- No vault, encryption, backup, synchronization, or real authentication
- No deployment, no GitHub Actions, no remote backend
- No automatic booking or messaging
- No AI API for daily summaries
